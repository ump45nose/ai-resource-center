## 酒馆的操作方式

生产安装目录：`/vol2/1000/Docker/sillytavern/extensions/ai-resource-center`。刷新酒馆后，在扩展设置中展开“AI 资源中心 · RP”，填写中心地址和私有文件中的 RP 凭据，点“保存并读取”。

选定酒馆原生连接，再选择对应中心 RP 连接，点“关联当前连接”。关联不会覆盖当前连接。“应用中心配置到原生连接”是独立的明确操作；“上报酒馆已保存配置”只提交已保存字段。角色卡、世界书、提示词、采样预设和未保存草稿不参与同步。

没有替用户选择生产中当前连接的绑定，也没有批量替换酒馆配置。RP 凭据目前限定导入的 40 条连接；之后新增 RP 连接时需在中心生成包含新连接的限定凭据。中心暂停已绑定连接后，酒馆从下一次生成阻止该连接；不会中断当前生成。版本冲突在中心显示双方字段，处理后再由酒馆应用。

New API 的全局自动测试实际为每分钟开启。三个已明确归为 RP 的旧网关入口：<https://cdn.moe-atelier.site>、<https://gensoukyou.xyz>、<https://share.inliver.com>，已从启用改为手动停用（status=2），排除旧网关批量测试；酒馆直连配置没有修改。原状态、网关组和回读在 [RP 迁移回执](verification/rp-migration.json)，其余网关测试规则保留。

## 自动评价与客户端配置

每分钟读取新增网关调用，每小时重新计算；权益修改、上报和评估结束也会计算。只有明确设为自动托管且已回读的 New API 通用/生图连接会被调整。RP、客户端限定连接和人工固定项不参与公共网关调整。

额度截止与可用窗口边界按分钟核对；样本不足的连接临时退出后恢复接管时的优先级。通用/生图连接必须先接入 fn 网关，才能生成应用或评估配置；不会暗中导出绕过 fn 的直连配置。

最近七天少于 30 条有效记录时保留原优先级；限流、余额、账号验证、key、输入和取消不计作长期质量失败。限流或额度问题会影响当前可用性，后续真实调用成功可恢复。没有结束时间的资源投放公告只记时刻，不推导开放窗口。

准备评估配置只创建专用推理身份并固定渠道，不会运行 Agent。请在现有客户端执行自己的任务，再登记区间和评价；结束会停用评估 token。客户端绑定按实际协议直连，缺少请求记录显示未采集。

Magpie、Claude Code、Codex、OpenCode、Hermes Chat/Cron 的配置生成已实现。Magpie 使用协议 URL 字段，Hermes 使用原生 providers 配置；Chat/Cron 分开身份。配置生成与“人工确认真实任务成功”分开保存。未对用户所有客户端逐一执行真实任务。
