# 多设备与客户端配置同步

## 范围

设计中心、Magpie 与多台设备/多个客户端之间的配置发布、应用和回执。复用已安装 Magpie 的同步与客户端适配；RP 沿用酒馆集成。本轮交付设计，不改变本机同步、登录或默认模型，也不向现有 WebDAV 写入。

## 依据和决定

- 本机 Magpie 0.1.1244；现有 WebDAV 含 key 和 Agent 模型同步。以官方同版本源码核查，避免将 main 新功能当成本机能力。
- 通用/生图优先分发固定 fn 网关入口；上游优先级调整留在 fn。客户端限定连接可经本机 Magpie 使用，保留原客户端条件。
- 原生同步为双向、按分区取较新值；不适合按设备分配资源及凭据。中心增加独立配置源，Magpie 领取后复用已有目录、客户端字段应用与漂移检查，不另写每个客户端的适配。
- 中心供应商缓存与个人供应商分开，排除原生整套备份/同步；明确跟随中心的 Agent 字段也须在收集和恢复两侧排除。个人供应商和 Library 保留原有原生同步。
- Agent 当前选择默认留在本机，仅明确接管的绑定自动应用。外部修改显示差异，等待采用本机选择或应用中心配置。

## 验收

不同设备的默认模型互不覆盖；多客户端复用 Magpie 现有适配；配置生成、原生同步、客户端文件应用和真实任务验证分别有依据。共享域内外部改动可见；不同凭据域互不泄露。客户端限定渠道的原协议、认证及请求头进入真实客户端请求，RP 不进入 Magpie 分发及测活。
