## 扫描、测试与恢复

`POST /scans` 使用 `requestId, channelIds` 或 `siteIds`。省略范围表示所有允许扫描的资源；显式空数组不接受。最多五站并发，同站目录、指标依次采集。按渠道“禁止测活”标签及相同凭据的关联限制排除，不再按 RP 分类或同站域名一刀切。

扫描结果包含网站、目录、个人 key 和站方统计各自的状态，不将目录列出模型当作任务成功。`GET /channels/{id}/candidates` 返回验证候选，`GET /models` 查询完整模型状态。

`POST /evaluations` 提交 `requestId, channelId, modelId, taskRef`，等待原 cron 的正常执行。不配置 taskRef 时，必须先明确启用小任务验证；仅普通 OpenAI 兼容文字请求支持这个小任务，不伪造 Claude Code 客户端身份。

通过后可自动创建 apply 操作，或使用 `POST /channels/{id}/apply`，携带 `requestId, modelId`。网关按具体模型使用独立托管映射，先通过隔离模型别名验证，再开放普通模型名。写入前比对上次回读，外部修改显示冲突，不循环覆盖。

第二阶段由新版负责后续托管，`GATEWAY_WRITES=true`；旧库没有自动托管渠道，不会并行调整同一配置。周期扫描和生成任务分开开启；当前启用状态见 `/api/v2/maintenance`。管理中心不进入推理路径。

## cron 适配

`integrations/cron_adapter.py` 提供 `publish/prepare/result/flush`，只接入现有执行入口，不新建、立即执行或恢复任务。接入配置是 access 脚本生成的私密 JSON，可增加 `adaptedTaskIds` 和 outbox 路径。

任务目录可这样上报，读取原任务文件，不改计划：

```sh
python3 integrations/cron_adapter.py --config /私密路径/cron-access.json \
  --publish-profile /home/hermes/.hermes/profiles/lingjun
```

只有已经在原入口接上单次配置与结果回执的任务，才加入 `adaptedTaskIds`。其他任务显示待适配，不能冒充已经支持。

原任务取得执行权后调用 `prepare(task_id, run_id)`，将返回的 configuration 仅交给本次推理运行；遇到 `not_applicable` 保持原配置，明确绑定 skip 才跳过。不修改全局 profile。配置中的 key 不记录日志。

运行结束使用同一 runId 调用 result，包含实际 channelId、原始 modelId、result、occurredAt、usedFallback，以及能确认的 acceptance。适配器先保存私密待发回执再上传，失败后只补交结果，不重跑业务。任务结果不再作为一条额外请求计入调用账本。

当前未选择或修改用户的业务 cron，适配器不自动插入 Hermes 调度器。现有 Hermes 的立即运行会改变暂停状态，本实现不调用该入口。酒馆新版联动与客户端配置分发属于下一阶段；旧版 RP 被动上报和已保存连接接口继续兼容。

已只读接入 Lingjun 的 91 个任务，其中 38 个暂停；尚无任务声明完成单次配置适配，所以不会启动任务验证。后续按所选任务接入 prepare/result，再将该任务标记为已适配。

## 第二阶段：扫描、验证与恢复

维护编排在 `server/maintenance.mjs`，周期和等待原因在 `server/maintenance-policy.mjs`。定时与页面操作走同一条链：扫描网站和 key 模型目录，筛选认可型号，优先等待已适配 cron，否则执行启用的小任务，验收后按模型同步 New API。

正常扫描默认每天，维护每 6 小时，关闭站点每天，鉴权问题每周；模型复验每周。网站失败仍读 API。站方连续失败的型号不自动派发；没有站方指标时可用个人 key 目录中的认可型号验证。目录及站方观察与自己的任务结果分开保存。候选能力分类是筛选规则，短任务通过只代表该任务完成，不自动评为优质。

自动验证默认每渠道每轮最多 3 个、每天最多 30 次，小任务输出最多 2048 Token。次数在派发时占用，重启不重放结果不确定的任务；当天上限和候选范围可在 WebUI 维护设置调整。原始 key、连接地址或协议变化后，旧版验证不能恢复新配置。

网关准备独立模型连接和随机验证别名，用临时身份固定渠道、关闭备用。只有验收通过、配置版本一致的模型才切换到正常模型名。失败的新验证连接回读停用；调用记录由 New API 单路采集，小任务记录标为 evaluation，不重复计数或充当真实质量样本。
